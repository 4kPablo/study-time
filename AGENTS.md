# Study Time

Local-first, Spanish-language (Argentinian) study-habit tracker. React 19 + TanStack
Start (file-based routing) + TanStack Query + Tailwind CSS v4 + shadcn/ui
(`new-york` style, lucide icons), built with the `@lovable.dev/vite-tanstack-config`
preset. Design intent doc: `docs/design.md`.

## Deploy

- Cloudflare Pages (Git integration): build `bun install && bun run build`, output
  `dist`. See README for the dashboard settings. `vite.config.ts` sets
  `nitro: { preset: "cloudflare-pages" }` so the SSR worker lands in
  `dist/_worker.js`; `wrangler.toml` pins the Pages name, output dir and compat flags.

## Commands

Use **bun** (lockfile is `bun.lock`):

```sh
bun install
bun run dev       # dev server + route tree generation
bun run build
bun run lint      # eslint; prettier runs as a rule, so lint failures are format issues
bun run format    # prettier --write .
bunx tsc --noEmit # typecheck (no npm script for it)
```

There is no test suite.

## Architecture

- **All data is client-only.** No server functions exist (verified). Don't add
  `createServerFn` or a backend for app state.
- Persistence: IndexedDB via `idb-keyval` under `study-time:data:v1`, wrapped by
  `src/features/core/repository.ts` (memory-cached, seeded on first load). React
  Query hooks in `src/features/core/queries.ts` are the only way components should
  read/write data — add new mutations there, never call `idb-keyval` directly.
- Domain types, categories, seed data, and pure stats helpers live in
  `src/features/core/`. Feature folders: `core` (data), `focus` (timer, session
  flow, zustand UI/timer stores), `dashboard` (cards).
- `src/features/focus/timer-store.ts` is a zustand store persisted to
  `localStorage` — ephemeral timer state only.
- UI sounds are synthesized with Web Audio (no assets): engine in `src/lib/sfx.ts`,
  persisted on/off preference in `src/lib/sfx-store.ts`. `SfxLayer`
  (`src/components/layout/sfx-layer.tsx`, mounted in root) delegates sounds: a
  `data-sfx` attribute overrides the generic click (`toggle`/`confirm`/`success`/
  `cancel`), `data-sfx="none"` opts out. Components must guard `window` access for
  SSR (the app does render server-side).

## PWA

- `public/site.webmanifest` + `public/sw.js` make the app installable. Favicons
  and PWA icons live in `public/` (`favicon.ico`, `favicon.svg`,
  `favicon-96x96.png`, `apple-touch-icon.png`, `logo.png`,
  `web-app-manifest-192x192.png`, `web-app-manifest-512x512.png`).
- The service worker registers only in production (`import.meta.env.PROD`), cache
  name `study-time-v3`. Bump the cache name when changing the precache shell.
- `src/components/layout/install-button.tsx` (in `AppShell`) handles
  `beforeinstallprompt` and shows iOS instructions; keep `window` guards there for SSR.

## Routing & generated code

- File-based routes in `src/routes/` (`__root.tsx` is the only root layout; root
  shell wraps everything in `AppShell` + `SessionLayer` — keep `<Outlet />`).
- `src/routeTree.gen.ts` is auto-generated by the dev/build pipeline and
  prettier-ignored. Never edit it; regenerate by running dev/build.
- No Next.js/Remix conventions (`src/pages`, `app/layout.tsx`, etc.).
- `src/server.ts` is the SSR entry (wired via `vite.config.ts`); do not remove.
- `vite.config.ts`: do NOT add plugins already provided by
  `@lovable.dev/vite-tanstack-config` (listed in the file header) or the app breaks
  with duplicate plugins.

## Styling

- Dark-only design, defined in `src/styles.css` (Tailwind v4 CSS-first config).
- Use semantic tokens only — never hardcode colors in components. Category colors
  via `cat-*` tokens (see `category-styles.ts`), reusable surface via the `panel`
  utility.
- Prettier: `printWidth: 100`, double quotes, semicolons, trailing commas.
- UI copy and dates must be in Spanish; use date-fns `es` locale as the existing
  routes do.
